# قدرات الخويلدية

موقع اختبار القدرات (القسم الكمي) لمدرسة الخويلدية الثانوية، مع قاعدة بيانات PostgreSQL لحفظ **المستخدمين** و**درجات الطلاب**.

## بنية المشروع
```
backend/                 الخادم (Node.js + Express) — واجهة برمجية JSON تحت /api
  server.js              نقطة التشغيل: يربط المسارات ويقدّم ملفات الواجهة
  db.js                  الاتصال بـ PostgreSQL وإنشاء الجداول تلقائياً
  lib.js                 الجلسات والصلاحيات والتحقق من المدخلات
  achievements.js        الإنجازات والمستويات ونقاط الخبرة (XP)
  routes/                auth · results · users · students · analytics (+ الملف الشخصي)
frontend/                الواجهة (HTML/CSS/JS بلا أدوات بناء)
  index.html + quiz.js   صفحة الاختبار
  profile.html           ملف الطالب: المستوى والإنجازات ونقاط القوة والضعف وسجل الدرجات
  dashboard.html         لوحة المعلم
  login.html             الدخول وإنشاء الحساب
  common.js · style.css  شريط التنقل والمساعدات ونظام التصميم (فاتح/داكن)
  questions.js · analytics.js
```

## المزايا
- **الملف الشخصي للطالب**: المستوى ونقاط الخبرة، 13 إنجازاً (برونزي/فضي/ذهبي) مع شريط تقدم لكل إنجاز لم يُحقَّق بعد،
  إحصائيات (الاختبارات، المتوسط، أفضل/آخر درجة، أطول سلسلة أيام)، نقاط القوة والضعف، وتطور الدرجات. ويفتح المعلم ملف أي طالب من لوحة المعلم.
- **الإنجازات** تُمنح تلقائياً عند حفظ كل اختبار وتظهر للطالب فور انتهائه، وتُحفظ مع تاريخ تحقيقها.
- تصميم جديد بوضعين فاتح وداكن (يتبع إعداد الجهاز أو زر التبديل في الشريط العلوي).
- تسجيل دخول وإنشاء حساب للطلاب (كلمات المرور مشفّرة bcrypt).
- بنك أسئلة كامل بوضعين: فردي (تُحفظ درجة الطالب تلقائياً عند نهاية الاختبار) وفرق.
- صفحة **درجاتي** للطالب: كل محاولاته، المتوسط، أعلى نسبة.
- **سجل الطلاب** (أول تبويب في لوحة المعلم): يضيف المدير/المعلم اسم الطالب وصفه ودرجته (من 100) ومستوى تقدمه (0–100% مع شريط تقدم) وملاحظات، مع التعديل والحذف والبحث والتصفية بالصف.
- **التحليلات** (أول تبويب في لوحة المعلم): لكل طالب، ولكل مرحلة، وللمدرسة ككل:
  الإتقان في 18 مهارة فرعية، نقاط القوة (≥ 75%) ونقاط الضعف (< 60%) مع توصية بالتركيز،
  الأداء حسب القسم ومستوى الصعوبة، المقارنة بين المراحل، الأسئلة الأكثر خطأً مع الخيار الخاطئ الشائع،
  تطور درجات الطالب، وقائمة الطلاب الذين يحتاجون دعماً. ويرى الطالب تحليله في صفحة «درجاتي».
- **لوحة المعلم**: كل درجات الطلاب مع بحث وتصفية بالصف وتصدير CSV (يفتح في Excel)، وإدارة المستخدمين (إضافة، تغيير كلمة المرور، حذف).
- الصلاحيات: `student` طالب · `teacher` معلم · `admin` مدير النظام (وحده يضيف المعلمين).

## قاعدة البيانات
تُنشأ الجداول تلقائياً عند تشغيل الخادم (`db.js`):
- `users`: id, username, full_name, password_hash, role, class_name, created_at
- `results`: id, user_id, score, total, percent, level, created_at
- `answers`: إجابة كل سؤال في كل اختبار (q_index, section, level, skill, picked, correct)
- `users.stage`: المرحلة (أول/ثاني/ثالث ثانوي)
- `students`: id, full_name, class_name, grade, progress, notes, updated_at
- `achievements`: user_id, code, earned_at — الإنجازات التي حققها كل طالب

## النشر على Railway
1. ادخل [railway.com](https://railway.com) ← **New Project** ← **Deploy from GitHub repo** ← اختر `Websit2`.
2. داخل المشروع: **+ New** ← **Database** ← **PostgreSQL**.
3. افتح خدمة الموقع ← **Variables** وأضف:
   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
   | `JWT_SECRET` | نص عشوائي طويل |
   | `ADMIN_USERNAME` | `admin` |
   | `ADMIN_PASSWORD` | كلمة مرور المدير |
   | `NODE_ENV` | `production` |
4. **Settings** ← **Networking** ← **Generate Domain** للحصول على رابط الموقع.
5. ادخل بحساب المدير، ثم أضف المعلمين من «لوحة المعلم ← المستخدمون».
